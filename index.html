Dataset setup

The names selected on the right are the patterns to plot or fit. Instrument, resolution, background, exclusions and phase-assignment edits apply to those selected datasets. Ctrl/Cmd+A selects all; Ctrl/Cmd+click adds one; Shift+click selects a range.

Selection and batch refinement

Copy suitable start values and refinement flags to the selected datasets in Parameters, then fit the selection. Individual fits keep a separate set of fitted values for each dataset. Global fits tie only the parameters marked shared; use local cells when the lattice varies between patterns.

Le Bail calculation

Observations, phase definitions and assignments belong to the project. Each method keeps its own values, refinement flags, background, sharing and results. Fits use the topmost selected dataset as the source of phase starting values. Reorder datasets to change the source. Phases and Parameters show the active calculation for the first selected dataset; deselect datasets to edit the starting model; select datasets on the right.

Parameter limits and shared parameters

A refinement keeps every parameter between its limits (type inf for none). Ticked “shared”, a parameter gets one value for all the datasets of a global fit that hold its phase (Sharing in the global fit, Refine menu, keeps some of them apart); unticked, one value per dataset. Scales and background stay local. Zero, displacement and transparency default to local and can be shared explicitly.

Settings

    Load one or more patterns from the Datasets tab, or use Simulate with any phase that has atoms. Define phases with or without atoms, then assign phases with Datasets tab → Phases… or Refine → Phases of the datasets…. Solve contains separate Le Bail, WPPF and Rietveld calculations of the same observations. Switching method tabs preserves each calculation’s values, fit flags, background, sharing choices and results in the project file. New calculations start from the current values. Phase definitions and dataset assignments are shared by the project; changing a structure invalidates incompatible saved results. During a Rietveld calculation, any phase without atoms is fitted by WPPF alongside the Rietveld phases.

    Select datasets on the right, choose Individual or Global, then select parameters to refine. Global fits allow a mixture of local and shared cell, atom, orientation, profile, zero-point and sample-geometry parameters. Scales and background remain local. Rietveld needs atoms; atomless phases use WPPF in a Rietveld calculation. Refine scales only fits all Rietveld phase scales in the selected patterns with other parameters held fixed; the results show their normalized weight fractions.

    Working with it

    Dataset setup is on the Datasets tab; the right-hand list only selects patterns for plotting and fitting. Hundreds of independent fits are queued with only the active worker jobs prepared in memory. Busy calculations lock editing; Stop or Escape cancels a fit or structure search.

    1. File, read powder patterns from the Datasets tab, or drop them on the window (Bruker, PANalytical, Rigaku, Philips, GSAS, CIF, two-column ASCII). New datasets appear at the top of the list. Set the wavelength, the polarisation and the fitted range in Instrument (Datasets tab), the background in Background, the regions to leave out in Exclude.
    2. Read a structure CIF for each phase, or make a new phase from its space group and cell: without atoms it is fitted by Le Bail or WPPF.
    3. In Datasets, use Phases… (or Refine → Phases of the datasets…) to define which phases each dataset contains.
    4. Tick what to refine in Parameters, or use the group checkboxes in Solve: background/scales, zero/lattice, peak shape; Rietveld also offers positions, B and occupancies. Press Fit (F9). Le Bail or WPPF first, to settle the cell and the peak shape, is the usual start. Global fits the selected patterns together: select A and C to refine what they share with those two only.
    5. With a WPPF fit done, open Solve → WPPF: test the space group, solve the structure, export the atoms to the phase, switch to Rietveld and fit again.
    6. Solve includes the results of the active calculation: R factors, weight fractions, atoms, reflections and extracted intensities; File saves them, the calculated patterns and the whole project; Report writes a PDF.

    The model

    ycalc(2θ) = background + Σphases Σhkl Ihkl · Ω(2θ − 2θhkl), Ω the peak shape of unit area, Kα2 included. Rietveld: I = S · m · Lp · P · |F|², with S the scale of the phase in the pattern, m the multiplicity, Lp the Lorentz-polarisation factor, P the March–Dollase factor and F the structure factor from the atoms. Le Bail: I is the share of the observed counts that the reflection gets in proportion to its calculated profile (Le Bail, Duroy and Fourquet 1988), partitioned again from flat at every cycle. WPPF: I is a free variable of the least-squares fit, non-negative, solved exactly at every step (variable projection, Golub and Pereyra 1973), so its standard uncertainty and its correlation with the cell and profile are those of a full Pawley refinement. The background is a Chebyshev series over the fitted range or a monotone cubic spline through anchors; points in excluded regions are calculated but not fitted. Choose Levenberg–Marquardt (LM), or parallel tempering (PT) followed by LM, in Settings → Refinement. Both respect limits and weights 1/σ²; standard uncertainties come from the normal matrix scaled by χ². Weight fractions (Rietveld phases) follow Hill and Howard.

    Requirements

    Open index.html through a web server (it reads sg/all.json and scatters/), for example python -m http.server in its folder, then http://localhost:8000/index.html. Fits, charge flipping and the Wyckoff search run in Web Workers; WebGPU, where there is one, speeds up the last two.

    The methods (WPPF, Le Bail, exact overlaps, constraints, the space-group test, charge flipping, the Wyckoff search) are explained in the documentation, with where each one stops being trustworthy. Powder 6 descends from PowderV2 (Dragoe, N. (2001). J. Appl. Cryst., 34, 535).

    Full documentation: Powder6_documentation.html (commands, file formats, parameters, structure solution, troubleshooting).

    Charge flipping: Oszlányi and Sütő (2004). Space-group test: Markvardsen, David, Johnson and Shankland (2001). Peak shapes: Thompson, Cox and Hastings (1987). Powder 6 descends from PowderV2 (Dragoe, J. Appl. Cryst. 34, 535, 2001).
