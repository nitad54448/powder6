# Moyo WebAssembly

Powder 6 bundles `@spglib/moyo-wasm` version 0.21.0 from the
[Moyo project](https://github.com/spglib/moyo). The package provides the browser
bindings and WebAssembly binary for crystal symmetry analysis.

The upstream package is licensed under MIT OR Apache-2.0. This copy is
distributed under the [MIT license](LICENSE-MIT); retain that copyright and
permission notice when redistributing it.

Upstream citation: Kohei Shinohara, *moyo: A fast and robust crystal symmetry
finder, written in Rust* (2026), [doi:10.6084/m9.figshare.31081162.v1](https://doi.org/10.6084/m9.figshare.31081162.v1).

The JavaScript module and binary are loaded locally from this directory.
Atomic coordinates are processed in the browser.
