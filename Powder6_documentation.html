Powder 6

Refine powder diffraction patterns in the browser. Several phases and several patterns in one session, each phase by Rietveld, Le Bail or WPPF, individually or in one global fit, with structure solution from the extracted intensities.

Overview

Powder 6 is a single page, index.html, that runs entirely on your machine. Nothing is uploaded. It descends from PowderV2 (Dragoe 2001). It does file reading, space groups, scattering factors, peak shapes, charge flipping and the Wyckoff search, together with Rietveld refinement, several phases and several patterns in one session, and global fits.

  • Many patterns, many phases. Every dataset holds its own value of every parameter of its phases. A phase can be in some datasets and not in others.
  • Three ways to get the intensities. Rietveld (from atoms), Le Bail (partitioned from the data) and WPPF (free non-negative intensities solved exactly at each step). Phases using different methods can share a dataset.
  • Individual or global fits. Fit each selected pattern on its own, or fit them together and decide per parameter whether it is shared or local.
  • Constrained models. Special positions, crystal-system cell metrics, GSAS-II style atomic constraints and symmetry-restricted anisotropic broadening are built into the parameter set rather than corrected afterwards (see Constraints).
  • Constant-wavelength X-ray and neutron data, with Kα2, polarisation, sample displacement and transparency.
  • Structure solution. Space-group test, charge flipping and a Wyckoff-site search, handing the atoms back to the phase for a Rietveld fit.
  • Local and private. Fits run in Web Workers. Settings and the Solve options are kept in the browser's local storage. Projects are saved as compressed .project files (.archive and the .powder6 files of earlier versions open too), with observations stored once and persistent calculation history.
Scope. Powder 6 is for educational and research use. It implements standard algorithms but is not a substitute for fully validated, peer-reviewed packages such as GSAS-II, FullProf or TOPAS for analyses intended for publication.

Getting started

Run it

Open index.html through a web server, not by double-clicking it. The page loads workers, shader files and databases with fetch, which browsers block on file://. From the folder that holds index.html:

python -m http.server 8000

then open http://localhost:8000/index.html. Any static server works. Use a current Chrome, Edge or Firefox. The Wyckoff search requires WebGPU in Web Workers. LM fits, intensity extraction and atomic-model symmetry analysis run on the CPU; parallel-tempering fits and charge flipping have CPU fallbacks. See GPU and CPU execution.

A first fit

  1. Click load the demo in the Datasets panel when it is empty, or type demo in the command line (NaCl and Si, simulated with Cu and Co radiation), or read your own pattern with Read patterns… (Datasets tab or File menu) or by dropping it on the window.
  2. Check Datasets → Instrument: wavelength, radiation, polarisation and the 2θ range to fit.
  3. In Phases, read a structure CIF or make a new phase from a space group and cell.
  4. In Commands → Method, pick a method. Start with Le Bail or WPPF to settle the zero, cell and peak shape.
  5. Tick the groups to refine (background, zero and lattice, Sample, Resolution) and press Fit selected datasets or F9.
  6. Read the agreement factors in the results. Then, with atoms in the phase, switch it to Rietveld and tick positions, B and occupancies. The order that works is described in Strategy.

Selection, history and project storage

One dataset selection drives fitting and plotting. Inspecting a selected member does not change membership. Choose All datasets, a range (Shift+click) or individual checkboxes; a search box above the list narrows it by name; it appears when there are more than eight datasets. Delete selected removes the checked datasets after confirmation. FIT uses each selected dataset's current values for the active method. Conflicting shared starting values in a global fit require an explicit choice.

A completed fit updates the dataset's working values. For example, if Le Bail changes a lattice from 3.5 to 3.49 Å, the next Le Bail fit starts at 3.49 Å; the shared phase starting model remains at 3.5 Å. Edit the dataset value, undo the fit or explicitly restore a saved run to return to an earlier starting point. The other way round, editing the cell or the atoms in Phases changes only the starting model (what a dataset the phase is newly assigned to starts from); to carry it into datasets that already hold the phase, press Starting model → datasets… under the atoms of the phase (cell, atoms or both, for every dataset holding the phase or one of them; the fit results are cleared, the refinement flags kept). Dataset → starting model… does the reverse: a dataset’s values, its fitted ones after a fit, become the starting model. The Structure block of a phase draws its structure, with coordination and distances, for the starting model or a dataset’s model. Empty Datasets shows only the loading hint and demo link. The phase chooser appears once a phase exists; Method setup appears once both phases and datasets exist.

Each method retains its own setup, background and results. Switching methods restores those values and reuses an unchanged calculated plot when its cache is still valid. Inspecting a saved fit similarly reuses its evaluated pattern. Editing the model or acquisition invalidates the affected cache. Wavelength, doublet ratio and fitted range remain acquisition properties of the dataset across method changes.

History stores immutable calculation checkpoints with values, flags, bounds, settings, uncertainties, intensities and the model needed to interpret them. Results → Run selects what is displayed and exported without changing the working setup.

Concepts

Rietveld, Le Bail, WPPF

Every dataset is modelled as

y_calc(2θ) = background + Σ_phases Σ_hkl height · profile(2θ − 2θ_hkl)

The peak shape is the same whatever the method. The method decides where the intensity of each reflection comes from. Whatever the method, the reported intensities are integrated areas (peak height times the area of the unit-height profile), not heights: a height under-weights high-angle reflections by the full profile broadening.

MethodIntensityUse it to
RietveldS · m · Lp · P · |F|² from the atoms: scale S, multiplicity m, Lorentz-polarisation Lp, March–Dollase factor P.Refine a known structure: positions, occupancies, B, scale, weight fractions.
Le BailPartitioned from the observed pattern (Le Bail, Duroy and Fourquet 1988), starting from a flat set each time, so the intensities depend only on the parameters.Fit cell and peak shape without a structure.
WPPFFree intensities, solved exactly and non-negatively at each step by variable projection (Pawley 1981; Toraya 1986; Golub and Pereyra 1973). Standard uncertainties are those of a full Pawley fit.Extract intensities with uncertainties for space-group testing and structure solution.

Phases with different methods can share a dataset. A phase without atoms can only be Le Bail or WPPF. A phase whose last atom is deleted switches to Le Bail.

Le Bail in detail

The net observed intensity (observed minus background) at each point is shared between the reflections that contribute to it, in proportion to each reflection's calculated profile at that point; summing the shares gives an intensity for each reflection. Powder 6 applies this in a way that keeps the result a function of the parameters alone:

  1. Start. A Le Bail fit begins as a WPPF fit. Variable projection is exact and does not need a good starting point, whereas the partition does: from a poor cell or profile it extracts intensities at the wrong places and the cycles can settle on a profile that only fits those intensities.
  2. Cycles. The classic algorithm then takes over. At the top of each iteration the intensities are re-extracted from a flat start (every reflection given the same height) and iterated until the relative change falls below 10-4, with a floor of 6 passes and a cap of 24. They are then held fixed for the whole iteration: for the baseline residual, for every column of the Jacobian and for the trial step. Only cell and profile parameters move.
  3. Why not re-extract at every evaluation inside the step. The extraction would quietly compensate for any change in width, flattening the χ² surface and making the widths indeterminate. Alternating extraction with least squares, rather than fusing them, is the actual Le Bail method.
  4. Background. The background is held at the values the first stage found while the cycles run. The partition gives every count under a reflection to that reflection, so a background refined in the same cycles can sink while the peaks broaden to take up the difference, a little more at every cycle.
  5. Stop. The cycles stop when χ² stops falling or every shift is below a tenth of its uncertainty, since a re-partition moves χ² a little by itself.
  6. Iterations. Maximum iterations is the budget of the whole fit: the WPPF start uses at most half of it and the cycles what it left (at least one).

Le Bail intensities are partitioned, not fitted, so they carry no covariance matrix: their uncertainties are the counting statistics of the observed points propagated through the partition fractions. This is why the space-group test and charge flipping use WPPF intensities.

WPPF in detail

The pattern is linear in every intensity, y(x) = Σ_j I_j φ_j(x; θ) + b(x), so for given non-linear parameters θ (cell, zero, profile widths) the optimal intensities are the solution of a linear least-squares problem, not something to iterate towards. Powder 6 solves it at every step and lets the minimiser search only θ (variable projection; the Jacobian of each non-linear parameter is projected on the complement of the intensity columns, Kaufman 1975). Two consequences matter: the intensities are exactly optimal at every iteration, and the search space is the dozen or so truly non-linear parameters instead of several thousand, which is what makes parallel tempering usable.

  • Pawley or WPPF? The model is the one Pawley introduced: every intensity a free least-squares variable. What differs is the surroundings. Pawley worked with constant-wavelength neutron data and a Gaussian peak; Toraya's whole-powder-pattern fitting was developed for laboratory X-ray data (Kα1/Kα2 doublet, asymmetric peaks, Lorentzian character), which is what Powder 6 is built for. Pawley's slack constraints on near-coincident reflections are not used: exact coincidences are reported as groups instead (see Overlapping reflections). All WPPF reflections of a dataset, whatever their phase, are solved together, so overlaps between phases are handled like overlaps within one.
  • Speed. The normal matrix of the linear step is banded (two reflections interact only where their profile windows overlap and the list is sorted by 2θ), so the solve costs O(n·b²) in the bandwidth b, not O(n³).
  • Non-negativity. An intensity is physically non-negative, but unconstrained least squares can split two overlapping reflections into a large positive and a large negative value that sum correctly. An active-set non-negative least-squares solve removes that region. The uncertainties are nevertheless taken from the unconstrained normal equations, so a reflection pinned at zero still reports how poorly it is determined. This is what lets the French–Wilson treatment in charge flipping avoid the upward bias that clipping to zero would cause.
  • Limits. The information in the data is unchanged: strongly overlapping reflections stay correlated, exactly coincident ones determine only their sum, and a poor starting cell is still a poor starting cell. The separable form makes the surface in θ better behaved, not convex.

Individual and global fits

The Mode selector appears only when two or more datasets are selected (with one dataset there is nothing to choose). Individual fits each selected dataset on its own, in parallel, starting from each dataset's current values for the active method. Global fits all selected datasets in one least-squares problem. In Global mode each refined parameter has a padlock: closed means shared (one value for all datasets that hold it), open means local (one per dataset). A dot on the padlock means shared by some of the selected datasets only. Refine → Sharing in the global fit edits this as a table. Scales and backgrounds stay local. If a shared refined parameter has different current values, choose a dataset value or enter a shared starting value before the global fit; cancelling leaves the model unchanged.

Instrument

Every session starts as a Cu X-ray tube (Kα1 1.540598 Å, Kα2 1.544426 Å, ratio 0.5, no monochromator); the source of the last session is not remembered, and a pattern whose file states a wavelength or radiation takes that instead. Datasets → Instrument… (also in the Data menu) sets, for the selected datasets:

  • Radiation: X-rays or neutrons (constant wavelength). Polarisation does not apply to neutrons.
  • Source: Cu, Co, Fe, Cr, Mo, Ag with the tabulated Kα1, Kα2 and intensity ratio, or your own λ1, λ2 and ratio I(λ2)/I(λ1). The ratio runs from 0 to 1; set it to 0 for a monochromatic beam or synchrotron (no Kα2).
  • Polarisation: tube without monochromator (K = 1), monochromator (with its 2θM), synchrotron (with the polarised fraction f), or none (K = 0). See Lorentz-polarisation.
  • Anomalous scattering: on by default for X-rays, with a checkbox to compare on/off calculations; disabled for neutrons. The bundled scatters/anomalous_chantler.json contains Chantler f′ and f″ in electrons for H–U, copied from Hephaestus's anomalous-scattering file. Each dataset uses linear interpolation in photon energy E = 12398.419843320025/λ1 (eV for λ1 in Å), without extrapolation; exact tabulated energies retain their values. Corrections use the neutral element even when f0 uses an ion. They enter the Rietveld structure factors as f = f0 + f′ + i f″; a powder line holds h and −h in equal parts, so its intensity is the Friedel average (|F(h)|² + |F(−h)|²)/2. The correction is evaluated at λ1 for the pattern, including its doublet model. It is ignored for neutrons and free-intensity methods.
  • Goniometer radius: used for displacement in mm and for transparency estimates.
  • Zero is a refinable 2θ shift. It is highly correlated with the lattice parameters: refine it with care, and preferably against a standard.

Lorentz-polarisation

The integrated intensity of a powder reflection is not |F|² alone:

I(hkl) = s · m · Lp(2θ) · |F(hkl)|² Lp = L · P

m is the multiplicity and s an arbitrary overall scale. The Lorentz factor for a θ–2θ scan is L = 1/(sin²θ cos θ) (the usual extra factor 4 is constant and is absorbed in s); it has no parameters and applies to every polarisation setting. The polarisation factor is the same expression for all models, normalised so that P(0) = 1:

P(2θ) = (1 + K cos² 2θ) / (1 + K)

Choosing 2θM

In Instrument, hover the Monochromator 2θ /° label or hover/focus its angle field for a table of graphite (002), quartz (10-11), Ge (111)/(220), Si (111)/(220) and LiF (200) take-off angles. The table uses the current λ1 displayed in that dialog and updates as you edit it or choose a source. It lists only reflections accessible at the current wavelength (λ1 ≤ 2d). Click any row to fill the angle field, or focus its crystal button and press Enter or Space. The Instrument dialog stays open until you Apply. These are approximate Bragg 2θ angles; choose the optic installed on the instrument, applying the perfect-crystal convention below when needed.

2θM is not free: it follows from Bragg's law at the monochromator, 2θ_M = 2 arcsin(λ / 2d_M), so the same crystal gives a different angle on every anode (graphite 002 sits at 26.6° on Cu and 12.2° on Mo).   • Geometry. The formula is the parallel case: the monochromator diffracts in the equatorial plane, as for a Johansson Ge (111) incident-beam crystal or a diffracted-beam graphite crystal on essentially every laboratory instrument. A monochromator mounted with its diffraction plane perpendicular to the equatorial plane gives P = (K + cos² 2θ)/(1 + K), a different function that no value of 2θM can imitate.
  • Mosaic or perfect crystal. K = cos² 2θM is the ideally mosaic result, right for graphite. A perfect crystal needs K = |cos 2θM|; to use it, enter the equivalent angle arccos √K (19.1° instead of 26.6° for graphite geometry, K = 0.894 instead of 0.800). The two differ by well under 2 % in P.

Choosing f for a synchrotron

Bending-magnet and undulator radiation is polarised in the horizontal plane, f typically 0.90 to 0.98 there. What matters is the orientation of the diffractometer: with a vertical scattering plane (usual for high-resolution work) the field is perpendicular to it, f ≈ 0.95–1.0 and P is nearly flat; with a horizontal scattering plane the field lies in it, f ≈ 0.05–0.1 and P → cos² 2θ, a severe correction that vanishes at 2θ = 90°. Getting this backwards is a much worse error than misjudging f by a few per cent.

Where Lp matters

  • Rietveld phases. Lp is part of the model: height = S·m·Lp·P·|F|²/A. Changing the polarisation changes the calculated pattern, so it can move the refined atomic parameters, B and scale. Set it correctly before refining a structure.
  • Le Bail and WPPF phases. Every intensity is a free quantity and absorbs Lp completely. The polarisation model cannot move a cell parameter, a profile coefficient, Rwp or χ². It changes the meaning of the refined intensities: the |Fo| derived from them, the input to charge flipping, the Wilson prior behind the French–Wilson correction and the space-group test.
  • |Fo|. An observed structure-factor modulus is |Fo| = √(Ihkl/(m·Lp)) on an arbitrary scale, where Ihkl is the integrated Kα1 area of the reflection (the convention of the Rietveld model, I = S·m·Lp·P·|F|²) and Lp is evaluated at the corrected peak position with the polarisation model declared for the dataset.

Background and exclusions

  • Chebyshev polynomial over the fitted range, 0 to 24 terms. The range is mapped to −1 … +1; the coefficients may have either sign and enter the model linearly, so their derivatives are exact. Changing the fitted range re-expresses the coefficients to preserve the existing background at retained angles, including when restoring another method’s saved background.
  • Spline through anchors whose heights are the parameters (monotone cubic Hermite, Fritsch and Carlson 1980), 2 to 200 anchors. Their 2θ positions stay fixed during refinement. In Datasets → Background each anchor is a row with its 2θ and its height (both editable, one header for the columns), a × that removes it (at least two stay) and the refine tick. The monotone form gives a smooth, physically realistic baseline without overshoot between anchors. Place anchors now and anchors>>n put them at the two ends of the fitted range and at the lowest point of equal stretches between them, never in an excluded region; new heights are estimated from the data and existing anchors keep their values. Ctrl+click on the pattern places an anchor at both cursor coordinates (on an anchor it removes it) and turns the background into a spline. This also works with logarithmic and square-root intensity axes. Right-drag an anchor to move it in angle and height; Escape cancels the move. Filled magenta squares are refinable anchors; hollow grey squares are fixed. Editing an anchor height in Parameters shows a yellow vertical line at its position.
  • Excluded regions, immediately after Background inside the dataset editor, are left out of the fit, the extraction and the statistics, but the pattern is still calculated there. Add zone asks for the start and the end 2θ of a zone; each zone is a row with its two boxes, an Apply tick and a × that deletes it. Untick Apply to compare a fit with and without a zone: the zone stays in the list but takes no part in the fit, the shading, the extraction or the statistics. These rows edit the active dataset tab (the command Excluded regions of selected… sets the zones of all the selected datasets at once). On the plot, Ctrl+Shift+drag marks a region and Ctrl+Shift+click inside removes it for the first selected dataset. Manual anchor placement also uses the first selected dataset; right-dragging edits the visible anchor under the cursor.

Space group

Type a symbol, a number or a Hall symbol, or press Browse for the space-group browser: filter by crystal system, centring and axis choice, search by number or symbol, and read the reflection conditions of the selected setting before pressing Apply. Every setting of a group is offered separately, because the reflection conditions differ between them (No. 62 appears as Pnma, Pmnb, Pbnm, Pcmn, Pmcn and Pnam). Applying a space group re-derives the sites of the atoms, the free cell parameters and the constraints that still hold (see Constraints).

Subgroups. Commands → Structure → Space group → ADDSYM → Subgroups… lists the maximal subgroups of the phase's space group: translationengleiche (same lattice, lower point group; Fm-3m → I4/mmm, index 3) and klassengleiche (same point group, a sublattice of index 2, 3 or 4, so a larger cell; Fm-3m → Pm-3m). Choose one and press Convert…: it opens with that group, the new axes and the new origin (Axes and origin set to Enter them), and the atoms are kept, with the sites the lower symmetry no longer relates split. Repeat for the next step down. Rows of one group type that differ only by axes or origin are shown once.

Finding higher symmetry. Open Commands → Structure → Space group → ADDSYM → Find higher symmetry… to analyse the starting model, a dataset’s Rietveld model, or after a Le Bail or WPPF fit the dataset’s refined cell with its atoms, with Moyo WebAssembly. The active dataset is selected initially. See Atomic-model symmetry for the controls, conversion and limitations, and Bundled Moyo code for the local engine files and license.

Converting to another space group. Phases → Convert… (left of Browse…) describes the structure in another space group or setting, as in International Tables A, 1.5: new axes (a′, b′, c′) = (a, b, c)P and origin p, x′ = P−1(x − p), G′ = PTGP, h′ = hP. The structure is expanded to the full cell, carried to the new axes and reduced with the new symmetry. A subgroup keeps every atom and splits the sites the lower symmetry no longer relates (Fe1 → Fe1a, Fe1b); a supergroup merges atoms the new symmetry relates, and is refused, naming the atom and the distance, unless the structure and each dataset’s refined positions have that symmetry within the tolerance (0.1 Å by default); another setting of the same group changes only the axes and origin (P21/c → P21/n, Fd-3m origin choice 1 → 2). Work them out (Axes and origin) searches axis changes with entries −1, 0, 1 and origin shifts in eighths whose cell fits the new crystal system within 3 %, preferring unchanged axes, then the most compact cell with obtuse angles, then the smallest shift; Enter them takes any transformation, e.g. “a+b,-a+b,c” and “0,0,1/4”, including centred or larger cells. The cell, positions, B, occupancies and fit flags of the starting model, of every dataset holding the phase (from its own values) and of their saved calculations are converted; the preferred-orientation direction and uniaxial broadening axes follow the axes. Fit results are cleared, atomic constraints and parameter links of the old atoms are removed, and Ctrl+Z undoes the conversion.

Monoclinic settings. All three unique-axis choices are supported. The unique axis is read from the symmetry operators of the setting, and the cell then offers the one angle that is free: β for unique axis b (P121/c1), γ for unique axis c, α for unique axis a. The other two are fixed at 90° and are not parameters. Reflection orbits and multiplicities follow the same axis, so the three settings of one lattice give identical peak positions and intensities.

Reflections

The reflection list is built from the symmetry operators of the selected setting. Every hkl inside the resolution sphere is mapped onto its orbit under the Laue group; the orbit is kept once, labelled by a canonical member, and its size is the multiplicity m in I ∝ m·Lp·|F|². Systematic absences are tested on that representative, which decides the whole orbit: h is extinct if some operator (R, t) satisfies hR = h with h·t not an integer. Working from the operators, rather than from a fixed index range per crystal system, matters wherever two Laue classes share a crystal system and have genuinely different sets of independent reflections:

SystemLaue classesWhat separates them
Cubicm-3m / m-3m-3 permutes the axes cyclically only, so (210) and (201) are independent; in m-3m they are equivalent.
Tetragonal4/mmm / 4/m4/m has no mirror exchanging a and b, so (hkl) and (khl) are independent. P4 has Laue class 4/m: a general reflection has 8 equivalents, not the 16 of 4/mmm.
Hexagonal6/mmm / 6/mAs for tetragonal.

In hexagonal and trigonal cells the special forms depend on the Bravais–Miller index i = −(h+k) as much as on h and k: a reflection lies on a mirror whenever any two of h, k, i are equal in magnitude, so (1 -2 l) and (2 -4 l) are special although |h| ≠ |k|. This follows automatically from the operators. The Laue class matters in two further places: the Stephens anisotropic-broadening terms allowed (see Profile symmetry) and the orbit sizes used by charge flipping (see Constraints in structure solution).

Atoms

Add atom… takes a label, an element or ion type, fractional coordinates, occupancy and B. Each atom shows its Wyckoff site; coordinates on special positions are constrained automatically. Relationships between atoms are made in the phase's Constraints section (Edit constraints in Datasets →), described in Atomic constraints. A CIF read with Read CIF… brings its atoms in the same way, and the sites are re-derived from the space group.

Atoms from CIF… reads the atom sites of a structure CIF into the current phase, replacing its atoms or adding to them; the phase keeps its own cell and space group, and a file in another space group or with a cell more than 2 % different is read with a warning. Fragment… puts a molecule (PDB, MOL/SDF V2000, XYZ or Z-matrix) into the current phase: its atoms are labelled by element (C1, C2 …, numbered past the labels already there) and placed with their centroid at a point of the cell (by default the point farthest from every symmetry element, so that the atoms sit on general positions) in the orientation of the file; a PDB with a CRYST1 cell can keep its own fractional coordinates instead. Peak shape

Each dataset has an instrument profile. Choose it in Datasets → Instrument resolution; TCH is the default. Every available family combines the instrument response with independent crystallite-size and microstrain broadening for each phase contribution. The Gaussian and Lorentzian widths depend on θ; the resulting peak is a pseudo-Voigt, pV(x) = η L(x) + (1 − η) G(x).

Profile typeParameters and widths

Units and conventions of X and Y

Instrument Lorentzian coefficients follow the GSAS convention, in centidegrees (1 cdeg = 0.01° 2θ): HL [°] = (X/cos θ + Y tan θ + Z)/100. X multiplies 1/cos θ, Y multiplies tan θ and Z is constant. The Gaussian coefficients are GSAS variances: HG [°] = √(8 ln 2·(U tan²θ + V tan θ + W))/100, with U, V, W in cdeg². Each phase contribution adds its own sample size (shown in nm) and strain (ppm), with Gaussian/Lorentzian mixing fractions. Size can be isotropic, uniaxial or ellipsoidal; strain can be isotropic, uniaxial or Stephens.

For orientation, with K = 1 and λ and D in the same unit, a crystallite size D gives a Lorentzian 1/cos θ coefficient of 18000 λ/(π D) cdeg (λ = 1.5406 Å and D = 100 nm give 8.8), and a microstrain S in µε gives a tan θ coefficient of 0.018 S/π cdeg (1000 µε give 5.7). These relations connect sample size and strain to the added Lorentzian widths.

Other programs. GSAS and GSAS-II use these names. FullProf uses the opposite ones, in degrees: their X multiplies tan θ (strain) and their Y multiplies 1/cos θ (size). To carry values over, exchange the two and multiply by 100: X = 100·YFullProf, Y = 100·XFullProf.

Anisotropic strain (Stephens)

Anisotropic microstrain, where broadening depends on direction in the crystal, is modelled by a fourth-order polynomial in the Miller indices (Stephens 1999). The refinable coefficients S400, S040 … are the symmetry-unique ones for the Laue class of the phase (see Profile symmetry). These are quartic reciprocal-metric variances (ppm²·Å-4); the strain width follows from √ΣS·d². This sample model is available with every instrument profile.

Position, asymmetry and truncation

Peak positions include the Kα2 doublet, zero shift, displacement and transparency. Instrument calibrations are saved in Datasets → Profile; sample broadening is saved from File. Each reflection is evaluated only within a finite window around its centre, from 8 FWHM for a Gaussian to 25 FWHM for a Lorentzian (interpolated with η) and never wider than 10° 2θ. The profile value at the window edge is subtracted from the whole peak as a small pedestal, so the profile reaches zero continuously rather than stepping off a cliff (a step would put a discontinuity in the pattern and in the derivatives). The exact area of the untruncated shape is carried along so that reported intensities are free of the truncation bias (the tails cut at the window are counted, as the background takes them up in the data). With the SL/HL asymmetry, which stretches one flank and compresses the other, that area includes the change the asymmetry makes, integrated numerically. The on-screen preview, final LM refinement, reported intensities and uncertainties use the same CPU implementation in double precision. PT can evaluate exploratory patterns on WebGPU, with numerical validation and CPU fallback as described below.

Preferred orientation

The March–Dollase axis of a phase (h k l, not all zero) is set in Phases (Preferred orientation) and its r, with its refine box, in the dataset's parameters (PO r). r = 1 means random orientation; r must lie between 0.1 and 5. The factor is averaged over each reflection's equivalents. Rietveld phases only.

Constraints

The exact constraints below remove independent refinement variables. Restraints instead add soft penalties, and limits restrict allowed values; these controls are distinguished explicitly below. A powder model has many more apparent degrees of freedom than the sample has. Powder 6 removes the redundant ones exactly, by eliminating dependent parameters from the least-squares problem, rather than by penalties or by correcting values afterwards. This description of elimination applies to exact constraints and links, not to the soft restraints listed alongside them. A constrained parameter has no Jacobian column of its own, takes no part in the count of refined parameters, and has the uncertainty that follows from its independent parameters. Special positions

An atom on a symmetry element has fewer free coordinates than three. Powder 6 finds each atom's site from the operators of the space group: the stabiliser of the position (the operators that map it onto itself within a small distance tolerance, using the minimum-image distance), the multiplicity N/|stabiliser|, the position projected exactly onto the site, and the free directions. The free directions are the null space of the stacked (R − I) of the stabiliser, in reduced row-echelon form with the columns taken z, y, x, so that x stays free whenever it can. Examples:

  • (x, x, x): one free coordinate, x. y and z are computed from it, and the Jacobian has one column, not three of which two are copies.
  • (x, 0, 0): x is free, y and z are fixed numbers.
  • (0, 0, 0), (½, ½, ½): no free coordinate. The three coordinates cannot be ticked.

The position is always r = r₀ + Σ u_f · basis_f, with uf the values of the free coordinates and r0 what the site fixes. This is why a special position is constrained, not corrected after each step: a refinement can never walk an atom off its site, and the standard uncertainty of a dependent coordinate is that of its master. Each atom shows its Wyckoff letter and site expression in the Phases tab. Adding or editing an atom, or changing the space group, re-derives the site; relationships that became impossible are trimmed (see below).

Rules the editor enforces

  • A parameter belongs to one relationship only: it is held, or it is in one equivalence or equation. (GSAS-II: a parameter is dependent in at most one constraint, and a held parameter in none.)
  • An atom appears at most once in a relationship. Equivalences and equations need at least two atoms, a hold at least one.
  • Multipliers are finite and non-zero (the first multiplier of an equivalence is always 1); the total of an equation is a finite number.
  • Coordinates fixed or dependent by site symmetry cannot be used. Only a free direction of a site can be constrained: (x, x, x) offers x; (0, 0, 0) offers nothing. The atom chips for such coordinates are disabled with the reason in the tooltip.
  • Constraints apply per component. To tie x, y and z, add one relationship for each, or use the mixed-site shortcut.

Editing values and refinement flags

Valid manual edits to an equivalence update its independent value and all dependent values, even when you edit a dependent textbox. Its refine flag remains disabled: only the independent flag determines whether the group is refined. A sum equation behaves differently: checking or unchecking any term updates all of its refine flags in the inspected dataset. Imported or older partially enabled sums appear mixed, with a warning; click a term to enable the whole group.

For Na1.occ + Cl1.occ = 1, entering 0.30 for Na sets Cl to 0.70; entering 0.40 for Cl sets Na to 0.60. Both refine checkboxes are checked together, but only one independent occupancy is refined. For sums with more than two terms, editing one value preserves it and recomputes the last other term; the remaining current values are retained. Changes must satisfy every term’s limits.

Bounds can remove the remaining freedom. Two occupancies limited to 0–1 and constrained to sum to 2 must both equal 1: the editor reports that the limits leave no freedom to refine. An attempt to enter 0.90 for either term is rejected because it would force the other to 1.10. To change the model, edit the total or a justified limit; a refine checkbox cannot create freedom that the equation forbids.

What happens when you apply one

  1. Starting values are aligned. For an equation, the current values are projected onto Σ mi vi = c inside the parameter limits (each value is moved along the multiplier direction and clamped to its limits; the monotone dependence of the sum on the shift is solved by bisection). If the equation cannot be met within the limits (for example a total of 3 for two occupancies limited to 0–1), the editor says so and nothing changes. For an equivalence, the dependents are computed from the independent parameter. Atoms are then put back on their sites.
  2. Previous fits are cleared. The statistics, uncertainties and intensities of the Rietveld calculation of the phase's datasets are invalidated, because the model changed. The change is one undo step.
  3. The fit eliminates the dependents. At each evaluation the dependent value is the affine function offset + Σ tk · xk of the free parameters, so derivatives are exact (chain rule), and the number of refined parameters is that of the independent ones. A dependent of fixed parameters is simply a constant, set once.

Bounds and uncertainties

  • Limits apply to dependents too. Constrained occupancies must remain within 0–1 as well as any tighter user limits; an invalid manual edit is rejected, rather than silently changing the constraint. If a dependent has a single independent term, its bounds are translated into bounds on the independent parameter (divided by the multiplier) so the minimiser cannot cross them; incompatible bounds are reported (“Incompatible constraint bounds for …”). With several terms the combination is checked at the starting values and at each step (“Starting values conflict with a constraint or the parameter limits”).
  • The uncertainty of a dependent is propagated from the covariance of its independent terms, var = Σjk tj tk covjk, including their correlation. It is not shown when a term is at a bound or the matrix is ill-conditioned, and the Parameters list says why. A coordinate whose uncertainty reaches half a cell edge is flagged as not constrained by the data.

When the model changes under a constraint

Deleting an atom, changing a site or the space group, or renaming a label can invalidate a relationship. Powder 6 trims it rather than refusing the edit: the atom (or a coordinate that became fixed by symmetry) is removed from the relationship; if the independent atom of an equivalence goes, the next atom becomes the independent one with multipliers rescaled; relationships left too small are dropped. Every trimming is written to the Log (“A1.x removed from: …”). Projects saved with the older plain “equal” groups are read as equivalences with multipliers 1.

Dos and don'ts

  • Constrain what chemistry demands (a shared site, a charge or stoichiometry sum, a common displacement parameter for chemically similar atoms), not what makes the fit look better.
  • Refine a mixed-site total only if scattering contrast allows it: Fe and Ni (Z = 26, 28) are nearly indistinguishable for Cu X-rays, and the occupancy ratio is then undetermined whatever the constraint.
  • Occupancy and B are strongly correlated; constrain one of them (or refine them in separate steps) when the data are poor.
  • Atomic constraints are linear. For bond lengths or angles, use Restraints, which penalize departures from a distance or angle window; an exact rigid-body parameterization is not provided. Wyckoff-search distance rules belong to a separate structure-solution calculation.

Links between parameters

Open Datasets → Links → Add parameter link…. Select the source dataset and independent parameter, target dataset and dependent parameter, multiplier and offset. The equation is target = multiplier × source + offset. Unlike an atomic equivalence, a link may connect different parameters, phases or datasets, and applies to the active calculation method. Rietveld, Le Bail and WPPF save and restore their method setups, including links. When a method has no saved setup yet, it starts from the current setup; verify that its parameter choices remain appropriate.

  1. Source and target must be available, independently editable parameter names. They may have the same name in different datasets; a parameter cannot link to itself in the same dataset.
  2. A target has exactly one source. A source may drive several targets. A target cannot itself be a source of another link: chains and cycles are rejected. Connect each target directly to the independent source.
  3. The multiplier must be finite and nonzero; the offset must be finite. The dialog uses displayed parameter units, including nm for crystallite size and the target’s display units for offsets. Choose physically meaningful relationships; the numerical link does not establish that two parameters have compatible physical meanings.
  4. Adding a link immediately aligns the target value, validates limits, clears affected fit results and records Undo. If the values exceed limits or conflict with another dependency, the link is not added. An atomic constraint and a parameter link cannot independently prescribe the same dependent parameter; incompatible combinations are rejected.

Editing and refining linked values

During refinement the target follows the source exactly and has no independent refinement variable. Its refine checkbox is disabled; tick the source to refine the relationship. With a fixed source, all its targets remain fixed by the equation. Source and target limits still apply.

You can edit either value manually. Editing the source updates every target. Editing a target computes source = (target − offset) / multiplier, then updates the other targets of that source. For example, with multiplier 2 and offset 0.01, source 0.03 gives target 0.07; entering target 0.09 sets source to 0.04. A limit violation rejects the edit without changing any participating dataset.

A source outside a particular fit is held at its current value. In an individual fit of a dependent dataset, a source in another dataset is therefore a fixed reference for that job. Use a global fit including the relevant datasets to refine the independent source jointly with the dependent patterns. Sharing and atomic dependencies must remain compatible with the link equations.

Remove deletes a link, with Undo, while retaining the target’s current numerical value. Decide whether to refine or fix the now-independent target. Links are stored with projects and the active method setup.

Restraints

Constraints remove parameters exactly. A restraint is softer: a distance or an angle that should stay near a known value is added to χ² as an extra observation, so the fit is steered toward chemically sensible geometry without fixing anything. Restraints belong to a phase (open Datasets → Restraints, immediately below Constraints, or Edit restraints… in the phase's Restraints section in Phases), apply to Rietveld calculations only and act in every dataset that holds the phase. In a global fit the phase counts once, shared between its datasets.

The rules use the same language as the distance constraints of the Wyckoff search, one per line, but A and B are atom labels of the phase (they are unique in a phase; case matters, though a label that differs only in case is accepted when it is unambiguous):

Sharing in global fits

In a global fit, sharing is itself a constraint: a shared parameter is one unknown for all datasets that hold it. Scales and backgrounds stay local. Atomic constraints and sharing combine, with two rules: the terms of one constraint equation must have the same sharing (all shared by the same set of datasets, or all local), otherwise the fit stops with “Constraint sharing conflict: use the same global/local sharing for …”; and a globally shared dependent parameter must have the same equation in every dataset that holds it.

Fitting

What gets refined

Tick parameters in the Parameters panel, or tick groups in Solve: background, zero and lattice, Sample, Resolution, and for Rietveld also atomic positions, B and occupancies. Sample selects the phase broadening parameters (or the effective profile parameters of a legacy profile). Resolution independently selects the active instrument broadening coefficients shown in Parameters → Resolution. Each group changes only its own parameters in the selected datasets. A dash in a group box means some of its parameters are ticked. Refine → Tick scales and background and the next entries tick the parameters of a step and of the steps before it. Parameters that a constraint makes dependent cannot be ticked independently; their flag is ignored.

Le Bail and WPPF show the dataset's Rietveld atomic model, labelled unused and read-only, in Phases and the Solve atom tables. Switch to Rietveld to edit or refine those atomic values. Structure exports use that same model while keeping the cell of the current calculation. Each method retains its own background and fitted results.

scales (and Refine → Estimate scales and background) estimate the scales and a constant background to get started; Refine → Fit scales only (untick the rest) unticks every flag of the selected datasets except the phase scales and fits them. Every fit also begins with one linear step on the scales and background (the model is linear in them), taken before the full fit.

Algorithms

Levenberg–Marquardt (LM)

LM is a gradient-based method for non-linear least squares that interpolates between Gauss–Newton and steepest descent. It converges quadratically near the minimum and is the method that gives the standard uncertainties. Powder 6 uses Marquardt scaling, solves the damped normal equations by Cholesky factorisation (an indefinite matrix means the normal equations are corrupt, and Cholesky fails exactly there, which makes the loop raise the damping and retry), holds limits by an active set, and caps the step per kind of parameter (Limits and step caps).

Derivatives are exact for background terms, scales and atom parameters (x, y, z, occupancy, B, through the unit profiles of the reflections), differences of the heights for the March–Dollase parameter, differences of the spline for anchors, and central differences (one-sided at a limit) for cell, profile, zero, displacement and transparency. With WPPF phases in the dataset, the Jacobian is projected on the complement of the intensity columns; with Le Bail phases, see Le Bail in detail.

Parallel tempering (PT), then LM

WebGPU PT. All three fitting methods try WebGPU automatically. The GPU performs proposals, cell and structure-factor calculations, all four profile types, backgrounds, joint non-negative intensity solves, χ² evaluation, acceptance decisions and replica exchanges. Initial and perturbed trial costs must agree with the double-precision CPU model within 0.1% of max(1, χ²); promising candidates are checked again on the CPU before the final LM fit. The GPU intensity solve uses a scaled KKT tolerance of 10−5. Unavailable devices, failed numerical checks, unconverged solves, device loss and resource limits restart CPU PT. There is a setup budget of one million Miller-index triples and 2048 potential free intensities per dataset; actual buffer limits may be lower. Results, the Log and text exports record the backend and fallback reason. A seed repeats the proposal stream for the same backend; GPU arithmetic can differ across devices, and CPU and GPU streams differ. The Wyckoff search already uses its own GPU replica-exchange search against extracted intensities.

PT, also called replica-exchange Monte Carlo (Swendsen and Wang 1986), runs several copies (replicas) of the model at fixed temperatures T = Tmaxr/(R−1), from 1 to the highest temperature. Each sweep every replica makes as many proposals as there are refined variables, each a Gaussian change of one parameter chosen at random (step scale from the local curvature and the parameter's step cap, widened by √T, reflected at the limits) and accepts it with probability min(1, exp(−Δχ²/2T)). Adjacent replicas then attempt to swap configurations, alternating even and odd pairs. A good solution found by a hot replica in a distant valley thereby percolates down to the cold ones. The best configuration is handed to LM, which converges locally and produces the uncertainties. A seed makes a run repeatable. PT costs many more model evaluations; use it when the starting cell or profile is uncertain.

  • WPPF under PT. The intensities are not searched; they are solved exactly at each evaluation, so a replica walks the same non-linear parameters it would in Le Bail mode, and its cost is the reduced objective, the residual after the intensities have been optimised. That is the function whose minimum in θ is the true minimum, so the Metropolis test and the swaps mean what they are supposed to mean.
  • Le Bail under PT. The PT stage and the first LM stage treat the Le Bail phases as WPPF (exact intensities at each evaluation); only the closing cycles are classical Le Bail. A cost that re-extracted partitioned intensities for every proposal would be non-stationary.
  • Which algorithm? LM alone when the model is already close; PT with the LM finish when it is not (typically a cell known only roughly).

Stopping

The fit stops when the relative change of χ² is below the tolerance twice in a row, when every refined parameter is at a limit or has no effect, or at the maximum number of iterations. Stop (or stop) ends a run; a stopped fit keeps nothing from the half-finished stage.

Weights

Supplied weights in a pdCIF take precedence over standard uncertainties. ESD, FXYE and XYE files retain their supplied σ values; otherwise the default is 1/max(counts, 1). Imported zero weights exclude those points even in unit-weight mode. Weights and uncertainties remain attached to their observations when the axis is sorted and are saved with the project.

Each point has weight 1/σ², with σ² the counts (Poisson) or the σ read from the file; a unit weight can be chosen in Settings. This is the right model for measured counts and for nothing else; see χ² and the weights for what happens when the intensities are not counts. The structure fitting steps (Wyckoff search and final coordinate refinement) use a different weight: 1/σ² of each extracted intensity from the WPPF decomposition, because the uncertainty of an extracted intensity comes from the decomposition and not from photon counting (see Wyckoff search).

Strategy

A sequential refinement is far more reliable than releasing everything from a poor starting model. The usual order, which the Refine menu steps follow:

  1. Set the model. Load the data, check the instrument (wavelength, doublet, polarisation, range), assign the phases, choose the space group and a starting cell. Exclude regions with artefacts or an unmodelled phase.
  2. Scales and background. Place the background (Chebyshev terms, or spline anchors close to the baseline) and let scales or the first step estimate them. Keep spline anchors out of peaks.
  3. Zero and cell (Le Bail or WPPF). Refine the lattice parameters and, if needed, the zero shift, so the calculated ticks fall on the observed maxima. If LM drifts to a poor solution from a rough cell, run PT once, then LM for the precise minimisation.
  4. Isotropic peak shape. Calibrate instrument widths against a standard, then refine sample size and strain for each phase contribution. Instrument and sample refinement have independent controls in Datasets.
  5. Asymmetry and shape. Introduce asymmetry (SL/HL, or the left/right widths) if there is a clear misfit at low angles, and η where it is free.
  6. Anisotropic broadening (last, and only if systematic misfits remain: some reflections consistently broader than the model). Refine only the symmetry-independent Stephens terms.
  7. WPPF for intensities. With a stable model, a final WPPF fit gives the most statistically sound intensities and uncertainties for the space-group test and structure solution. LM is generally the recommended algorithm for this step.
  8. Rietveld. Switch a phase with atoms to Rietveld. Release the scale first, then positions, then B, then occupancies, checking the difference curve after each. Use atomic constraints for shared sites and chemically similar atoms. Release the orientation parameter last, and only for a reason (visible texture).
Visual inspection comes first. Numerical indicators can mislead. A good fit has a difference curve of random noise centred on zero. Structured residuals (“M-shaped” features at peaks, broad humps where the background is inadequate, un-indexed peaks) mean a systematic error: wrong peak shape, unmodelled anisotropy or asymmetry, poor background, or an impurity phase.

Results and export

The selected completed calculation appears in its Results → Le Bail, WPPF or Rietveld tab, in folding blocks: Results and quantitative analysis (agreement factors, scale, weight fraction, RBragg and cell of each phase in each dataset that holds it), Atoms, Reflections (or Intensities for Le Bail and WPPF, with their uncertainties). The Run selector opens previous results without editing the working setup. Weight fractions follow Hill and Howard: W_p = S_p M_p V_p / Σ S_i M_i V_i, valid when every crystalline phase of the sample is in the model.

Agreement factors

R_p = Σ|y_obs − y_calc| / Σ|y_obs| R_wp = [ Σ w (y_obs − y_calc)² / Σ w y_obs² ]^½ R_exp = [ (N − P) / Σ w y_obs² ]^½ χ² = (R_wp / R_exp)² (reduced); GOF = √χ² R_Bragg = Σ|I_obs − I_calc| / Σ I_obs (Rietveld phases)

Rp is computed on the gross intensities (background included) and is sensitive mainly to the strong reflections. Rwp is the primary figure of merit because its weights follow the counting statistics across the whole pattern. N is the number of fitted points and P the number of refined parameters, including the determined intensities of Le Bail and WPPF phases, so the degrees of freedom are honest. RBragg uses Iobs obtained by sharing the observed net counts among overlapping reflections in proportion to the calculated profiles. χ² ≈ 1 is the target only when the weights are the true variances. A global fit also reports overall factors computed from the combined weighted residual sums, not the mean of the dataset percentages.

What does RBragg mean?

RBragg = 100 × Σ|Iobs − Icalc| / Σ|Iobs| compares integrated reflection intensities. The observed intensities are not measured directly: they are estimated from the profile by sharing the observed net counts among overlapping reflections, so they depend on the model, especially for overlapping peaks. A value of 0.04 % means a residual ratio of 0.0004; it alone does not establish a correct structure. RF is the same comparison on √I. Le Bail and WPPF phases refine free intensities, so their structural RBragg and RF are not defined and are omitted. Judge a structure by Rwp, the difference curve and physical plausibility too.

Powder 6 has no Williamson–Hall plot. Read crystallite size (nm) and strain (ppm) directly from each dataset’s phase contribution. They remain independent of the instrument coefficients for every available profile family.

Uncertainties

A refined value is printed in the crystallographic compact form, a = 5.4639(3) Å: the parenthesis is the standard uncertainty in units of the last digit shown, so this reads 5.4639 ± 0.0003. The value is rounded to the digit its uncertainty reaches and no further; the uncertainty is quoted to one significant figure, except where its leading digit is 1, which gets two (rounding 0.00012 to 0.0001 would misstate it by 17 %).

The uncertainties are the diagonal of the covariance matrix from the final normal equations, scaled by the reduced χ²: σj = √(χ²red Cjj), with χ²red = χ²/(N − P). They are the precision of the fit, not the accuracy of the measurement: they exclude sample displacement not modelled, any systematic error in the wavelength, and (with a fixed background) the background itself. A cell edge good to 3 × 10-4 Å by this measure can still be wrong in the third decimal for reasons the refinement cannot see. Parameters on a limit have no uncertainty. A parameter that a constraint makes dependent has the uncertainty of its independent parameters, with their correlation (Bounds and uncertainties).

Ill-conditioned profile refinements

Uncertainty unavailable means that the final joint covariance could not be estimated. It does not establish that every displayed parameter is unconstrained: one redundant combination can prevent inversion of the whole matrix, including uncertainties for otherwise measurable parameters such as zero shift. The dataset parameter list shows no s.u. with an explanation on hover. Fit diagnostics in Datasets, Results and saved reports identify locally dependent combinations, including combinations of three or more variables, and variables with zero derivative. The check uses a unit-diagonal normal matrix so different parameter units do not determine which variables are flagged. It does not manufacture uncertainties using extra damping or a pseudoinverse. Diagnostics are retained in calculation history and projects.

In the instrument model the Gaussian variance is U tan²θ + V tanθ + W. A negative V is common and is allowed; the combined variance must remain non-negative over the fitted range. Powder 6 checks the endpoints and any interior minimum. A negative instrument variance can be hidden by sample broadening or the smooth minimum-width continuation. Once the Gaussian width is far below the sampling floor, its coefficients have very little effect on the pattern, so their refinement becomes unstable. The diagnostic does not reset coefficients or change refinement flags.

Instrument and specimen broadening cannot always be separated from a single unknown specimen. With isotropic Lorentzian broadening, instrument X and inverse crystallite size both multiply 1/cosθ, while instrument Y and microstrain both multiply tanθ. Refining the instrument term and all corresponding sample terms together can leave an undetermined exchange between them. Gaussian strain can similarly trade against instrument U. A good Rwp cannot resolve that ambiguity.

For sample size/strain analysis, determine the instrument resolution from a suitable standard with known or negligible sample broadening, load that calibration and keep its coefficients fixed while refining the sample. When fitting the calibration standard, fix its sample broadening instead. Release width and asymmetry terms gradually after the peak positions agree, retaining only parameters supported by the data. These practices follow the IUCr refinement guidelines and International Tables: Rietveld refinement. Numerical diagnostics describe the current fit and refinement flags; they are not a substitute for instrument calibration.

χ² and the weights

χ² ≈ 1 is the right target only when wi is the real variance of yi. The Poisson weight assumes σ² = y, which is exact for raw counts and for nothing else. Three ways a dataset stops being counts:

  • Normalisation. Synchrotron data are often divided by a monitor, the ring current or the exposure time. A pattern whose strongest peak reads 100 “a.u.” would, as counts, scatter by ±10 at the peak and by about a quarter of its own height in the background. If the trace is visibly smoother, the numbers are not counts.
  • Averaging. Multi-analyser crystals, strip and area detectors and repeated scans average many measurements into each point. That cuts the noise by √n and leaves the scale alone, so √y overstates σ.
  • Smoothing or rebinning. Both correlate neighbours, which removes scatter without touching y. This cannot be undone afterwards: fit the unsmoothed data.

The relationship is linear: with w = 1/y, multiplying every intensity by k multiplies χ² by exactly k. A run reporting χ² = 0.05 says its data sit about twenty times below a count scale; scale the intensities up by twenty before loading and χ² arrives near 1. If a σ column comes with the file, Powder 6 uses it and the problem does not arise.

  • Unaffected by a wrong weight scale: the refined parameters (a constant factor on all weights does not move the minimum), Rwp and Rp (ratios in which the scale cancels) and the standard uncertainties (the covariance is scaled by χ², which cancels the error exactly). Intensity uncertainties scale with the intensities, so the relative ones are invariant. A low χ² is therefore not a reason to distrust the table.
  • Broken: χ² as a figure of merit, Rexp = Rwp/√χ², and any judgement “χ² is near 1, so the model is adequate”. Read Rwp and the difference curve instead.

The failure is asymmetric. A χ² far below 1 is almost always this scale problem and leaves the model intact. A χ² far above 1 can come from an over-optimistic σ, but much more often it is a real deficiency (a missing phase, a wrong peak shape, an unmodelled background) and should not be scaled away.

Overlapping reflections

Two reflections closer together than their profile width have nearly parallel derivatives. Intensity can move from one to the other with almost no change to the calculated pattern, so the data cannot say how it divides between them: the normal matrix is near-singular in that direction and the diagonal of its inverse blows up. A large σ there is the fit reporting, correctly, that the reflection's share is undetermined; it is not a failed fit, and the peak may look perfect on screen. What is determined is the total of the cluster. Its uncertainty needs the full covariance (var = Σij covij), because the off-diagonal terms are large and negative and it is their cancellation that makes the sum well determined; adding the individual variances in quadrature gives a hugely pessimistic total. Kα2 belongs in the decision of what overlaps: at high angle the satellite lands on unrelated reflections. Use cluster totals, not individual values, for anything downstream.

Exactly coincident reflections

Some sets cannot be separated at all. In a cubic F cell 333 and 511 have the same h²+k²+l² and therefore the same 2θ, the same profile and identical columns in the normal matrix; so do 700 and 522, and a dozen more pairs; accidental coincidences in low-symmetry cells do the same. The linear system is then exactly singular in those directions, and the solver (a modified Cholesky that repairs only the pivots that fail, Gill and Murray 1974: a pivot at or below 10−8 of its own diagonal, a column all but identical to earlier ones) puts the whole group intensity on one member and leaves the others near zero, so that the several hundred intensities that are determined are not biased by a damping term large enough to cope with every coincidence. The split within such a group is arbitrary; the sum is not. Without a warning a coincident pair would read as one strong reflection and one absent one, a conclusion the data never supported. Powder 6 flags these rows overlap in the Intensities table and in the saved reflection files, and the intensity of a weak reflection held at zero by the non-negativity is flagged at 0; its σ is still that of the unconstrained solution. Read the group, not the rows, for a space-group test or a structure solution.

Structure solution

Use Commands → Structure for setup and Results → Structure for output. Start from a WPPF phase whose cell and peak shape are settled: they decide what the intensities are. The order is extract, test the space group, then charge flipping and/or the Wyckoff search; the sites found are handed back to the phase for a Rietveld fit.

Check the result. Charge flipping and the Wyckoff search find candidates, not proofs. Look at the difference curve, the contacts, the density and the chemistry before trusting a solution.

1. Extract

WPPF determines reflection intensities during fitting. In Commands → Structure → WPPF intensities, choose the phase and dataset. The program automatically prepares uncertainties, correlations and the space-group test's precision block at the fitted values; this does not iterate or run another fit. Single-phase datasets are prepared after fitting; sources in multiphase datasets are prepared when selected. Previously prepared sources are reused until invalidated. The status reports availability or the need for a WPPF fit. ADDSYM does not require this preparation. All determined intensities remain available for structure solution and export. Refit after changing the cell, profile, model or point weights. Intensities are Kα1 areas; |Fo|² = I/(m·Lp) uses the dataset's polarisation model (Lorentz-polarisation).

2. Space-group test

Open Commands → Structure → Space group → Test · powder intensities. The test scores every setting compatible with the current Laue class against the extracted intensities and returns a ranked list of posterior probabilities (Markvardsen, David, Johnson and Shankland 2001). The separate ADDSYM section searches atomic coordinates.

Number of reflections specifies how many lowest-angle determined intensities enter the test. Its default is the available count, capped at 600 to bound the matrix calculation. Only whole numbers from 4 to the smaller of the available count and 600 are accepted; letters, fractions and excessive counts are rejected. The input and test stay disabled until enough intensities are available, and the available count is shown below the input. Changing the count rebuilds the precision block at the current WPPF model before testing, without iterating the fit; refit first if that model has changed. The old value 220 was a fixed computation default, with no relationship to the number of intensities in a dataset.

Principle

A candidate space group makes exactly one testable statement about a powder pattern: a particular subset of the reflections is systematically absent, so their true integrated intensities are zero. The question is not “does this space group fit?” but “are the reflections it forbids consistent with zero, given how well the data determine them?” A WPPF refinement makes this answerable because every intensity is a least-squares parameter, so the refinement returns not only the intensities but the normal matrix behind them, hence their full covariance. In a powder pattern overlapping intensities are strongly correlated: a reflection that should be absent can carry a large apparent intensity simply by borrowing it from a neighbour it cannot be resolved from. Judging each reflection on its own I/σ ignores this and can mislead in either direction. Le Bail intensities are partitioned, not fitted; they have no covariance, so the test needs WPPF intensities.

Statistical model

The true intensities are given a Gaussian prior that encodes what the group claims: variance 0 for reflections absent under S, a local Wilson-like scale τ² otherwise. Marginalising over the true intensities, the extracted ones follow a multivariate normal with covariance Q-1 + PS (Q the intensity precision matrix, PS the prior), so the evidence for S is one density evaluation:

−2 ln P(D|S) = Σ_{j∈f} ln τ_j² + ln det B_S − b_S' B_S⁻¹ b_S B_S = Q_ff + diag(1/τ_f²), b_S = (Q·Î)_f (f = reflections the group allows)

The quadratic form is the evidence carried by the would-be-absent reflections, evaluated with the full correlation structure. The log-determinant is an Occam factor: without it the group with no extinction conditions would always win, since nothing contradicts it. Posterior probabilities follow by normalising over the candidate list. The intensity block is marginalised over the lattice, profile and background parameters by a Schur complement, so their uncertainties are folded in. τ is estimated separately for each candidate from the reflections it says are present (a single global estimate collapses in centred lattices, where most reflections are absent). The original paper uses a Wilson (exponential) prior; a Gaussian of the same scale makes the marginalisation exact, so rankings are essentially unchanged but absolute probabilities are approximate.

Reading the result

Each row is a distinct extinction symbol: powder diffraction cannot separate groups that predict identical absences (centrosymmetric and non-centrosymmetric pairs, for instance), so those share one probability. The setting matters: Pnma and Pbnm are the same group but predict different absences relative to fixed axes and appear separately. Columns: P(SG|data), the number of refined reflections the group forbids (a group forbidding nothing is always in the list as a baseline), and ⟨I/σ⟩ and worst I/σ over the would-be-absent set (diagonal errors only; the familiar numbers, but not what drives the ranking). Choose a row to set the space group of the phase.

Requirements

  • Run the WPPF fit in a condition-free group. A reflection can only be tested if it was a parameter of the fit. If the fit was run in Pnma, every reflection Pnma forbids was never refined and carries no information, so the test is blind exactly where it matters. Use the group of the correct Laue class that imposes no conditions: P-1, P2/m, Pmmm, P4/m, P4/mmm, P-3, P-3m1, P6/m, P6/mmm, Pm-3 or Pm-3m. The test detects the situation and marks affected candidates as partial.
  • The Laue class is not under test, only the absences. It fixes the reflection orbits and multiplicities. A test run from Pm-3m cannot return Pa-3. If the Laue class is in doubt, run the test from each candidate in turn.
  • Exact coincidences (333/511 in a cubic cell) are handled, because the test is formulated in precision space, where Q may be singular while BS never is. The I/σ columns fall back to conditional estimates and are flagged.

What the search can establish

The selected atoms are expanded with the phase’s assigned space-group operators, then the lattice and full-cell positions are passed to Moyo. The assigned group number is not passed to the engine. Atom types are distinguished by their stored scattering type and by their occupancy, within Occupancies within; B values do not enter the symmetry search. Occupancy differences larger than that tolerance can therefore reduce the detected positional symmetry even when the coordinates are close.

In P1, every atom of the full cell must be present. Typing P1 into the space-group field of an asymmetric-unit model changes its symmetry without generating the missing equivalent atoms; use Phases → Convert… when the full structure must be preserved in a subgroup. If every tolerance returns P1, inspect the actual full-cell atom list, types, occupancies and cell. A known composition or an expected space group alone does not supply missing coordinates.

The result characterizes the supplied model at the chosen tolerances. A powder pattern may not distinguish a small distortion from a higher-symmetry model: refine the alternatives and compare the data, geometry and chemistry.

3. Charge flipping

The running panel reports preparation, GPU shader loading and compilation, then the calculated cycles. Preparation uses an animated indicator; percentages begin once cycles have actually completed. GPU startup waits are bounded, and a stalled or failed GPU falls back to the CPU for the remaining starts of that search. Stop is available during preparation as well as iteration.

Principle

Diffraction gives amplitudes |F| but not phases. Charge flipping (Oszlányi and Sütő 2004, 2008) iterates between real space (electron density ρ on a grid) and reciprocal space, enforcing one simple constraint in each. In real space, a correct density is non-negative almost everywhere, so every voxel with ρ below a small positive threshold δ has its sign flipped; this deliberately wrong perturbation drives the phases towards consistency. In reciprocal space, the Fourier transform of the flipped density is corrected by reimposing what is known: the measured amplitudes, the point-group symmetry and the systematic absences, keeping the calculated phases. Reflections that were never measured stay free, which lets the map extend beyond the data. The threshold is in units of the map's own RMS density σ, so it is scale-independent.

The agreement tracked every cycle is R = Σ_c |√I_calc,c − √I_obs,c| / Σ_c √I_obs,c, summed over measured peaks c, not individual reflections: a powder pattern cannot tell overlapping reflections apart, and scoring them separately would score noise. Icalc,c is the total calculated intensity under peak c. A run that has found the structure typically drops below R ≈ 0.15 and then oscillates; above ≈ 0.30 it has usually not converged. The best iterate of the run is kept, not the last. Weak and negative intensities are replaced by their posterior expectation (French and Wilson 1978), which is why the WPPF uncertainties of zero-clipped intensities matter.

Space-group constraints in the loop

Classical charge flipping works in P1, discarding the symmetry and letting the algorithm rediscover it, which is a safeguard when the group is uncertain. Powder 6 keeps that mode (λ = 0) but by default uses the selected space group inside the iteration. Five different constraints come from it, and they behave differently.

  1. Orbits: symmetry equivalents share one intensity. A WPPF fit reports one intensity per symmetry-unique reflection. Its equivalents hR are generated from the actual operators of the group and placed on the P1 grid. The Laue class is not the holohedry of the crystal system: P4 has Laue class 4/m, so a general reflection has 8 equivalents, not 16; likewise -3 versus -3m, 6/m versus 6/mmm, m-3 versus m-3m. Spreading one intensity over twice as many positions as exist would put half of it on reflections that are not equivalent. Within an orbit the amplitudes are equal, |F| = √(Iobs/m). Hard constraint, every cycle. Only the phases are free.
  2. Overlap: distinct reflections may share one peak. Reflections that are not symmetry-equivalent can fall at the same 2θ (exactly, as 511/333 in a cubic cell, or accidentally). The pattern gives only their sum. Such reflections are grouped into a cluster and its total is re-partitioned between them each cycle in proportion to the current calculated values (the idea of Le Bail extraction applied inside the loop; Baerlocher, McCusker and Palatinus 2007). The split is free; the total is fixed. Symmetry equivalents must be equal (constraint); overlapping distinct reflections are free to differ (unknown). Letting the members of an orbit float would discard exactly the information the space group provides.
  3. Systematic absences are excluded and held at zero. Reflections forbidden by centring, screw axes or glide planes are removed before the orbits are built and their grid points are forced to F = 0 every cycle. Leaving them free lets the density break the centring outright (for an F or I lattice that is most of the reciprocal grid). A fitted reflection that the selected group forbids never becomes an ordinary charge-flipping reflection; if it overlaps an allowed reflection, its corrected intensity stays in the measured cluster total and is re-partitioned among the allowed orbits only. An isolated forbidden reflection with raw I/σ ≥ 3 is inconsistent with strict symmetry: a strict run (λ = 1) is refused and names an example, while λ below 1 may still be run for diagnosis. The result records how many forbidden reflections were excluded, transferred from clusters or significant while isolated.
  4. Symmetrisation of the phases. For an operator x′ = xR + t the structure factors of a correct structure satisfy F(hR) = F(h) exp(−2πi h·t). Each cycle the members of an orbit are reduced to a common representative, averaged and pushed back: F ← (1 − λ)F + λFsym. λ = 0 imposes nothing (classical P1); λ = 1 is the exact projection, which converges faster and puts the solution on a standard origin. The trade-off: strict symmetry cannot recover from a wrong group and will happily converge to a low R for a structure that does not exist. If the group is uncertain, run at λ = 0 as well: a density that is genuinely consistent with the group will symmetrise well afterwards without having been forced to. Without the symmetry operators of the group, the effective λ is 0.
  5. Weak reflections are freed, not forced. The rules above impose |Fobs| on every ordinary reflection. The weak fraction exempts the selected weakest units: their calculated moduli are kept and their phases advanced by π/2 each cycle instead (Oszlányi and Sütő 2005); their measured intensity is used only for the knowledge that they are weak. The perturbation can help the iteration escape the flat, featureless maps the 2004 algorithm can settle into. Classification is made once, before iteration, and cannot change as overlaps are re-partitioned. By default (clusters) the unresolved peak clusters are ranked by total observed intensity per reciprocal-grid member and every orbit in a selected cluster is flagged weak, which avoids classifying an arbitrary, changing overlap partition as if it were an independent measurement; the number of phase-shifted orbits can therefore exceed the number of selected clusters. Individual mode ranks each orbit by its own initial target intensity. This is a different mechanism from rule 2: overlap re-partitioning frees a reflection's share of a cluster while holding the total; the weak flip frees a reflection's modulus entirely and perturbs its phase. A reflection can be subject to both.

The CPU and WebGPU paths apply the same classification and operations. If the adapter cannot take the grid, the run falls back to the CPU with a message; the CPU at 128³ takes minutes per start.

4. Wyckoff search

A WebGPU replica-exchange Monte Carlo search places atoms on trial Wyckoff-position assignments and scores them against the WPPF intensities. It needs the formula and, directly or by a scan, Z. It runs one complete search per value of Z, refines the coordinates of each best structure, and lists the solutions.

GPU work, CPU work and fallback

The Wyckoff calculation runs in a Web Worker and uses both processors. WebGPU is required for the search; there is no CPU-only Wyckoff search backend. A worker is a separate JavaScript execution context, not a promise that every step runs on the GPU. All data and calculations remain on your machine.

The objective

Each candidate is scored by score = (1 − wR2) − pen, and the candidate list is ordered by it. wR2 is the scale-only weighted residual over the observed group intensities; eliminating the optimal multiplicative scale gives

wR2 = √( 1 − (Σ w Ic Io)² / ( (Σ w Ic²)(Σ w Io²) ) )

This is invariant to overall scale but deliberately not to an additive shift: centring the intensities would silently fit a constant structure-factor intercept, which has no physical place in this model. Reflections the powder pattern cannot separate are summed into one group first, so the comparison is made where the measurement exists. Each group is weighted by 1/σ² of its total when usable WPPF uncertainties exist, σ² being the members' variances plus twice their WPPF covariances (large and negative for overlapped lines, so the total is far better determined than the sum of variances says); if at least one complete group has a σ, incomplete groups receive zero weight (never 1 or 1/I); only when no group has a usable σ is the whole problem unweighted. The final coordinate refinement uses the same policy and the same scale-only form, and reports the weighted residual it minimised, wR(F²).

These weights are fixed constants of the search (SW_DEFAULTS in js/swarm_wyckoff.js); only the Shape weight is a control. They steer the search and never rank its results: candidates are ranked on the fit to the intensities alone, and the distance rules are then applied as filters.

The total is multiplied by a factor that ramps from 0.2 at the start of a run to 4.0 at the end: geometry is nearly free early, so the search can pass through crowded configurations between two good basins, and expensive late, so the answer has to be physically legal. Archived bests are stored unscaled and re-scored at the current weight when compared. Because every geometry term is soft, a winning candidate can still be illegal; the result stage therefore re-checks floors, bare upper bounds and exact or at-least coordination counts as hard filters, and repeats the check after coordinate refinement. A violating structure is rejected rather than reported, which is why a run can report “search positions kept” after refinement broke a rule.

The search starts with only the first 25 % of the reflection groups (lowest angle first) and has all of them active by 60 % of the run (resolution ramp), because a low-resolution picture of the intensities lets the swarm find the right basin before high-angle detail makes the landscape rough. The running wR2 during the ramp is therefore not comparable to the final one.

Under the hood the search is a replica-exchange ladder of 8 rungs at fixed temperatures from 5×10-4 to 0.05 (in correlation units), proposal widths adapting towards a 30 % acceptance, swaps every 10 generations. A proposal moves one independent site, or all of them; when a distance rule has a count and Polyhedron moves is above 0 %, that share of the proposals are polyhedron moves instead: one centre of the rule and its nearest partners are translated together, the partners are rotated about the centre, or they are put at one distance inside the rule's window and, for a shaped rule, on the ideal shape best aligned with the shell. Moving single atoms nearly always breaks a shell, so these moves let the search explore positions and orientations of whole polyhedra; they are scored and accepted like any other proposal, so a shell whose partners are shared with another centre is simply moved less often. Temperatures are fixed, not annealed: a single chain that anneals into a wrong basin has no way back out. Stopping returns the best structure found so far. The GPU kernel has fixed capacities: 32 independent Wyckoff sites in one assignment (summed over elements), 8 elements, up to 4096 operators. Distance rules and coordination slots are sized per run when the kernel is compiled: 8 rules and 64 slots unless the constraints need more, up to 32 rules and 256 slots. A run that needs more is refused with a message naming the total and the limit; nothing is silently truncated. These limits and the defaults of the form are kept in one file, js/wyckoff_limits.js, read by the page, the worker and the kernel.

Assignments, waves and screening

Assignments that give the same intensities and distances are searched once: two assignments related by an origin shift (in quarters of the cell) or the inversion through the origin that maps the space group onto itself describe the same structure (P-1 has eight equivalent inversion centres; Pnma 4a and 4b are equivalent). The log says how many were left out.

Each assignment needs its own sub-swarm, so the particles hold only a few assignments at once (10 at 512 particles); the rest wait in later waves. When the assignments need more than two waves, the search runs in two stages. Screening: every assignment is searched for 10 % of the iterations (at least 60, capped at the requested full-search iterations), one restart, and its best is re-scored on every reflection group. Full search: the best two waves’ worth continue from what the screening found, with all iterations and restarts, and are polished by the final quench. A long enumeration (hundreds of assignments, which used to mean hundreds of full waves) therefore costs a few full waves. The progress bar covers both stages and every Z; it reads “screening i/n” during the first.

Restart count, progress and stopping

Restarts counts the initial start as well as the reseeded starts. With Restarts = 20, each full-search wave for each Z gets 20 starts in total: the first start followed by 19 reseedings. Chains receive fresh coordinates, while each assignment's best candidate is retained across starts. Two full-search waves therefore run 40 wave starts for that Z; scanning additional Z values repeats their own plans. Screening waves use one start each, independently of Restarts.

The entered count is validated before the worker starts, again in the worker, and at the search entry point. Values above 10 are passed unchanged; zero, negative, fractional and invalid counts are refused. Increasing Restarts extends the full search approximately in proportion, while screening and the closing quench are additional work. The progress readout names the stage, wave, restart and Z so a new wave or Z does not look like a reset of the requested count.

Seed and repeatability

Seed. The initial coordinates of every chain, every restart, the replica exchanges, the Gaussian proposals and the per-chain seeds the kernel runs from are all drawn from one 32-bit number. The search prints it when it starts and keeps it in the result, in History and in saved projects. Leave the field blank and a new seed is drawn for each run; type a reported seed and the search repeats exactly from the same extracted intensities, settings and assignments. That is what makes two settings comparable on the same stream of starts instead of on luck, and what lets a search that worked be run again.

Stop or Escape asks the worker to stop cooperatively, preserve its best available candidates and finish the available result's coordinate refinement; the closing quench is skipped or interrupted. Wait for the stopping/refinement message to finish. Pressing Stop again terminates the worker immediately: finished Z results and a live best already received by the page can be kept, with unfinished coordinates identified. Stopped or failed searches may therefore complete fewer starts than requested. The Log gives a summary; the full search log, settings and available results remain in History and saved projects.

Distance constraints

Helper. The Helper button to the right of the box opens the same tabbed dialog as the restraint Helper, on the elements of the formula unit (it is greyed out until a formula unit that can be read is given). Geometry writes a coordination shell (count, or a shape: linear, triangle, tetrahedron, square, octahedron), a nearest-distance window or a shortest contact between two elements. Molecule reads a PDB, XYZ or Z-matrix and writes the bonds of each element pair: A B N lo/hi when every A has N neighbours B, the nearest B when the counts differ, nothing when some A has none; elements outside the formula are left out. Suggest writes a shortest contact for every pair of elements, a factor (0.8) times the sum of their covalent radii. Add collects the rules in one box (the first rule of a pair is kept, duplicates and conflicts are reported, and the kernel limits are checked); Copy puts them on the clipboard, and only pasting them into the box applies them; Close closes the Helper without changing anything.

One rule per line; blank lines and lines starting with # are ignored. Element symbols are case-insensitive and must appear in the formula; anything else is reported as an error rather than skipped. The general form is

ElemA ElemB [count] dmin/dmax [shape]

Everything except the two symbols is optional. What matters is which of four mechanisms a line switches on:

FieldWhat it does
dminA hard floor on the pair. It replaces the Shortest-contact value for this pair, in either direction, so a rule can hold one pair further apart than the global floor or admit an approach it would forbid. Charged as a clash penalty that grows with the depth of the overlap. Costs no rule.
dmaxWith no count: the nearest partner must be within it. A pure nearest-neighbour condition, applied in both directions when the two elements differ, so it costs two rules (one when both symbols are the same). With a count: the upper edge of the window the shell is measured against.
countA coordination number: 4 exactly four, 4+ at least four. The kernel keeps the count nearest partners and charges each by how far it misses the window, so the penalty is graded by distance. Directed and never mirrored: costs one rule and count slots.
shapeOnly after a count and an upper distance: linear (2), triangle (3), tetrahedron (4), square (4, planar), octahedron (6); the count must be the shape's. Two letters or more of a shape's name are enough when they belong to one shape only: lin, tri, tet, sq, oct, even li, tr, te, oc. The angles between the count nearest partners are charged against the shape's (180°, 120°, 109.5°, and 90° or 180° for square and octahedral pairs), so the shell is held as a rigid-ish polyhedron within each centre's own neighbours, which an element-wide O–O rule cannot do. A soft restraint like the others, not a hard filter. The shape also keeps the centre off positions whose site symmetry the polyhedron does not have (a tetrahedron or a triangle cannot sit on an inversion centre). Costs no extra rule or slot.

Two rules and twelve slots, well within the budget; the third line costs nothing because floors live in the clash matrix, not the rule table. No Pb–S rule, because there is no Pb–S bond: constraining a distance you have no chemical reason to constrain is the commonest way to make the right answer unreachable.

  • Direction matters. A coordination number is tested from its first element outward. S O 4 1.40/1.80 asks every sulfur for four oxygens; O S 4 1.40/1.80 asks every oxygen for four sulfurs, which in a sulfate is false and is paid on every evaluation. Writing both is two independent demands (two rules, eight slots) and the box warns. Put the count on the centre of the polyhedron.
  • Running out of budget (32 rules, 256 slots; the rule count is the binding one, almost always through mirrored upper bounds): drop upper bounds you do not need (Pb O 8 2.00/3.00 says it better than Pb O /3.00 and costs one rule); turn windows into floors if you only care about the near side; constrain the cation polyhedra, not the anion–anion contacts, which follow from them.
  • A count without an upper distance counts the whole cell. S O 4 1.40/ asks for four oxygens further than 1.40 Å, which every oxygen in the structure satisfies; it constrains nothing and the box warns. A bare integer with no distance, S O 4, is rejected as ambiguous (it is equally a 4 Å distance).

Z, the density window and the scan

Z is the number of formula units in the cell and the one input that is neither measured nor refined. The stoichiometry is enforced by construction, so a wrong Z is fitted dutifully and reported with a residual that names no error. Blank Z does not estimate Z; it scans: every plausible value is searched in full and the best structure for each is offered, because a rule of thumb about cell volume is a prior and the intensities are evidence. The density fixes the relation Z = ρV/(1.66054·M), with M the formula mass (g/mol) and V the cell volume (Å³). The candidate list is cut three times before any GPU time is spent: the density window; what the space group permits (below); and whether a legal assignment of atoms to Wyckoff positions exists at all (a Z that cannot be built is discarded in milliseconds).

What the space group says about Z

Atoms of one element occupy Wyckoff positions, so their number in the cell is a sum of multiplicities. Let g be the greatest common divisor of every multiplicity the setting offers. For each element with subscript ke in the formula unit, Z·ke ≡ 0 (mod g), hence Z must be a multiple of lcme g/gcd(g, ke). For a pyrochlore A2B2O7 in Fd-3m the multiplicities are 8, 16, 32, 48, 96 and 192, so g = 8; oxygen requires 7Z ≡ 0 (mod 8), so Z is a multiple of 8, and of the eleven values from 3 to 11 only Z = 8 survives. The step and g are not always equal: in Pnma (g = 4) Fe2O4 gives a step of 2. In P1 and P-1 the rule says nothing (g = 1), correctly: a triclinic cell can hold any Z, which is why low-symmetry problems are the expensive ones. A fractional subscript (Fe0.5Ni0.5) voids the argument and the rule is skipped. The log states the derivation, not just the answer.

Solutions

Every surviving Z gets its own complete search (all restarts, the resolution ramp, the closing quench, the contact filter and the coordinate refinement). The plausibility ranking (volume per atom nearest 16 Å³, with a mild preference for a Z commensurate with the group order) decides only the order of the searches, so stopping early means the likeliest candidates are done. The results open with a Solutions table, one row per Z, with density, atoms per cell, assignment, search wR2 and wR(F²); click a row and everything below (coordinates, R factor, CIF, contacts, bond valences, structure plot, report) switches to it. Ranking is by wR(F²); a solution whose refinement did not run is placed below those that have one. A better wR does not make a Z right: more atoms mean more free parameters and often a better fit for that reason alone. Read the table beside the density, the contacts and the bond valences. Two Z that both fit respectably is a real result.

A typed Z is honoured exactly as typed and the density window is ignored; the panel still shows the implied density. A Z implying a density outside about 0.5–22.5 g/cm³ is refused (lithium is 0.53, osmium 22.59), because the Z, the formula and the cell cannot describe the same solid; the usual cause is Z counting atoms rather than formula units. A typed Z that breaks the space-group rule is warned about, not blocked.

How many sites a structure needs

The number of free parameters is three per general-position site, fewer for special positions, plus nothing else (scale is eliminated). A structure with 17 independent sites has around fifty parameters; the search needs enough effective observations to determine them (next subsection). Raising the number of sites per element increases the search space steeply; keep it at what the composition and the group demand.

Final coordinate refinement

After the GPU search and closing quench, the best structure of each Z is refined on the CPU as a local least-squares problem in the free coordinates, with the same scale-only objective and weights as the search, then validated again against the hard geometry rules. If the refinement breaks a rule the search positions are kept and the log says so. The reported wR(F²) is the weighted residual actually minimised; an unweighted figure printed beside a weighted refinement would describe a fit nobody performed.

When the ranking is withheld

A high fitness is not by itself evidence that a structure is right. wR2 compares a distribution of intensity, and a model can reproduce the few highest-leverage points while every other reflection is wrong by any amount. The number of reflections is also not the number of observations: because the residual is weighted, a group counts for its share of the observed denominator wiIi², and 1/σ² rewards sharp low-angle reflections and all but erases high-angle overlaps whose σ exceeds their value. The search reports the effective number of observations

N_eff = 1 / Σ p_i², p_i = w_i I_i² / Σ_j w_j I_j²

which equals N when all shares are equal and 1 when one group is everything; a list of 35 groups is routinely 5 or 6 effective observations. Distance constraints count as observations: a coordination-shell rule asking for n partners adds n pseudo-observations per independent site (not per atom in the cell), reported separately from Neff because a structure held up by restraints is a different claim from one determined by the data.

The behaviour has two thresholds, measured as (Neff + restraints) per free parameter of the best candidate:

  • Below 1.0: the ranking is withheld. A model with at least as many free parameters as effective observations reproduces them exactly whatever the structure, so every candidate scores near 1 and the ordering is noise. The candidates are still returned and worth testing (the coordinates are real), but the list is unordered, the panel says “candidates, not a solution”, and no best is claimed.
  • Between 1.0 and 3.0: “thin data”. The ranking is kept, because a correct structure can and does appear at this ratio (a correct ab initio solution of PbSO4 at 1.83 is the reason the threshold is not 3), but the gap between leading candidates carries little weight: check the chemistry and the refinement wR before accepting one.

To lift a withheld ranking, extract more reflections (particularly at high angle, where severe overlap leaves σ/I near or above 1 and the weighting correctly discards them) or add distance constraints, which count; or reduce the free-parameter count with a smaller Z or higher-symmetry sites. This is a test of meaningfulness, not of quality: above it a low score is still a real answer, and below it a high one is not.

Fourier maps

A Fourier map shows the scattering density of the cell. It is the natural next step after a solution or in the middle of a Rietveld refinement: a difference map (Fobs − Fcalc) shows where the model lacks density (a missing atom, a wrong element, an under-occupied site) and where it has too much; the observed map (Fobs) shows the atoms the data support; 2Fobs − Fcalc and the calculated map are also offered. The block sits in Commands → Structure beside the space-group test, charge flipping and the Wyckoff search, uses the same phase and dataset chosen at the top (so it works for a single phase, in any dataset that holds it), and shows its result in Results → Structure → Fourier map.

How the map is made

  1. The reflections come from the WPPF extraction (the same intensities as the other tools; they are prepared automatically). The phases come from the model: the atoms of the phase, with their values in the dataset or in the starting model (Atoms from). So the map shows the model’s own atoms best, and a difference map shows only what the model lacks.
  2. A powder line holds several reflections. The observed intensity of each overlap group of the extraction is shared among its reflections in proportion to m·Lp·(|Fcalc|² + ε), the partition of the Rietveld method; ε is a small share of the mean |Fcalc|², so a reflection that the model forbids can still come out non-zero. One scale factor puts the observed amplitudes on the scale of Fcalc. Reflections the extraction does not have keep their calculated amplitude, so they do not enter a difference map.
  3. The coefficients on the whole reciprocal sphere to the chosen resolution d (blank: the smallest d extracted) are summed by an FFT on a cubic grid (a power of two, at most 128³; Finer grid doubles the points per axis). F(000) is left out, so the map is relative to its mean; σ is its standard deviation.

Reading the result

  • The isosurface is drawn at a level in σ (the density viewer of charge flipping: drag to rotate, wheel to zoom). For a difference map, Holes (negative) draws the negative surface instead. Atoms of the model are drawn in the map.
  • The peak table lists the extrema above the chosen Peaks above (σ) (default 4; peaks of 3σ or less are usually noise), one per set of symmetry-equivalent positions (Copies), with the nearest atom and its distance. Heights are in e/Å³ for X-rays and fm/Å³ for neutrons, approximate because of the single scale factor.
  • Add atom… on a positive peak puts it into the phase: you name the scatterer, since a peak cannot, and the site is found from the position. Compute the map again to see what is left. A positive difference peak within about 1 Å of an atom usually means a wrong element or displacement, not a new atom.
  • Save map writes the grid as JSON (the format of the charge-flipping density); Save PNG the view.

Limits: phases from the model mean a bad model gives a biased map; severe overlap shares intensity by the model, which smooths a difference map towards the model; anomalous dispersion is not included in the phases. Maps are recomputed on demand and are not stored in projects.

5. Contacts and bond valence

Each solution has a structure plot (cell, atoms with covalent-radius bonds; Cordero et al. 2008), a contact table and a bond-valence analysis. The wR says the fit converged; this table says whether the result is chemistry.

  • Coordination number is the number of neighbours within a cutoff (default 3.5 Å, with element-specific limits so that a sulfate sulfur and a lead are not judged by one number). The count depends on the cutoff, which is stated under the table.
  • Bond-valence sum (Brown and Altermatt 1985; Brese and O'Keeffe 1991): s = Σ exp((R0 − d)/b) over the coordination shell, with b = 0.37 Å and R0 from the Brese–O'Keeffe table, compared with the formal valence of the site. The verdict is plausible within 15 % of the formal valence, borderline within 30 %, and check beyond (Brown 2009 on the method as a validation tool).
  • Which atoms are anions and in what oxidation state is a choice: the analysis states the assignment it used. A wrong oxidation state gives a wrong verdict for a right structure.
  • Limits. Hydrogen is not located by these methods, so hydrogen-bond contributions are missing from every oxygen sum in a hydrate or a hydroxide: expect them to read low. A mixed or partially occupied site will not balance against a single formal valence.

6. Back to the phase

The sites found replace the atoms of the phase in every dataset. Switch the phase to Rietveld and fit again, in the order of Strategy. Constrain shared sites and displacement parameters (Atomic constraints) and refine B last.

The formula unit, Z and the distance constraints of the Structure commands belong to the project: they are saved with it and not kept by the browser between sessions.

Bundled Moyo code and license

Powder 6 includes a local copy of the public @spglib/moyo-wasm package, version 0.21.0. The compiled WASM binary and JavaScript bindings are distributed with the application. No npm installation, compilation, external service or CDN is needed to run this copy. Serve these files over HTTP with the rest of Powder 6.

rv_phases.js selects the model and calls SGConvert.symmetryJob in sg_convert.js. That adapter builds Cartesian lattice vectors, fractional full-cell positions and integer identifiers for the stored atom-type/occupancy classes. It starts js/symmetry_worker.js, which initializes the bundled binary and makes this direct public API call:

import init, { analyze_cell } from '../lib/moyo/moyo_wasm.js';
await init({
  module_or_path: new URL('../lib/moyo/moyo_wasm_bg.wasm', import.meta.url)
});
const dataset = analyze_cell(JSON.stringify(cell), tolerance, 'Standard');

The worker returns Moyo’s dataset and Hall symbol. The adapter uses the returned space-group number, standardized lattice, axes and origin shift, converts Moyo’s column-major matrices to the application’s row-major convention, measures atomic mismatches and checks permitted cell adjustments. It sends no assigned group number to Moyo. Cancelling the dialog or changing its inputs terminates the worker. A load failure or timeout is reported in the search dialog.

Upstream offers MIT OR Apache-2.0; this bundled copy is distributed under the included MIT license. Retain its copyright and permission notice when redistributing the code. Attribution and the upstream citation are in NOTICE.md. See the Moyo source repository and public JavaScript API reference.

Browser checks in tests/project-symmetry.html, tests/addsym-pbso4.html and tests/convert-files.html exercise the public engine, model selection, conversion and undo. The PbSO4 fixture supplies known Pnma coordinates as a P1 dataset’s fitted values: 24 full-cell atoms become five independent sites. These checks verify the integration and transformations; they do not run an actual PbSO4 refinement.

Design rules worth knowing

  • One fit core. rietveld_core.js has no DOM access. The page, the worker and tests load the same file.
  • Plot colours are plain values. Variables read by canvas code (--plot-*, --series-*, --phase-*, --calc-line …) must be #hex, rgb() or px: a canvas cannot evaluate var() or color-mix(). The JavaScript keeps no colours of its own.
  • Single stylesheet source of truth. powder6.css defines all light/dark design tokens, layout and component rules in one place.

Powder 6 was developed by Nita Dragoe, Université Paris-Saclay, as a browser-based implementation of powder pattern decomposition, Rietveld refinement and structure solution. It descends from PowderV2 (Dragoe, N. (2001). J. Appl. Cryst. 34, 535) and includes whole-powder-pattern fitting (WPPF; Toraya 1986, with Pawley-type intensity extraction) and modern global optimisation.

The fit solvers (skyline Cholesky for covariance and uncertainties, the banded WPPF intensity solver, non-negative least squares and the minimisers) are implemented in the program itself. Atomic-model symmetry uses the locally bundled public Moyo WebAssembly code. These calculations require no content-delivery network. Plots are drawn on canvas and the PDF report by a built-in writer. Space-group lookup data and systematic-absence rules are derived from the Computational Crystallography Toolbox (cctbx).
